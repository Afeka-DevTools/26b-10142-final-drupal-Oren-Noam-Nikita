# כלי פיתוח - מטלה מסכמת (Docker, Drupal, Database)

## חברי הצוות
* אורן לוי
* נועם הרמבם

## על הפרויקט

### מטרת הפרויקט -
להקים אתר Drupal עם Database ייעודי (PostgreSQL / MySQL) באמצעות Docker.

## מה נדרשנו לבצע
* הכנת תשתית ליצירת הסביבה ב - Docker
* הגדרת Drupal ויצירת משתמש
* יצירת סקריפטים לניהול הפרויקט:
    * העלאת הסביבה לאוויר - 
    * גיבוי המידע ממסד הנתונים -
    * שחזור המידע מגיבוי קודם -
    * הורדת הסביבה וניקוי כל התוכן מהמכונה -

## מה ביצענו בפועל
* כתבנו סקריפטים באמצעות Shell, תוך שימוש בפקודות לצורך יצירת הסביבה ותפעול מסד הנתונים
* השתמשנו ב Docker בשביל ליצור סביבה של Drupal ובסיס נתונים (PostgreSQL)
* השתמשנו בקובץ Docker Compose על מנת לרכז את כל התשתית במקום אחד ולפשט את העלאת הסביבה לאוויר
* הגדרנו תיקייה ייעודית עבור התוכן והמידע של הפרויקט בשביל לפשט את ניהול המידע ומחיקתו בעת הצורך
* חיברנו את מסד הנתונים לאתר באמצעות משתנים שהגדרנו
* יצרנו קובץ משתני סביבה (.env) על מנת לאחסן משתנים שבשימוש בהרבה קבצים במקום אחד

**חשוב לציין -** במסגרת השימוש בקובץ `.env` למדנו שאסור להעלות את הקובץ הזה בחיים "בעולם האמיתי", אבל לשם המטלה הזו בחרנו להשתמש בזה מטעמי נוחות ולא מעבר.

### הכלים שהשתמשנו בהם -
* Linux (Ubuntu)
* Docker & Docker Compose
* Drupal
* PostgreSQL (SQL Database)
* Shell
* Git + GitHub

## מדריך מפורט (Step-By-Step)

### דרישות קדם
יש לוודא מראש שהתוכנות הבאות מותקנות -
* Git - [קישור להורדה](https://git-scm.com/install/)
* Docker Desktop (Desktop Application - Contains Docker Engine + Docker Compose) - [קישור להורדה](https://www.docker.com/get-started/)

### חשוב - יש לפתוח טרמינל (shell) מראש!

### 1. הורדת הפרויקט -
יש להוריד את הפרויקט למחשב -

```bash
git clone https://github.com/Afeka-DevTools/26b-10142-final-drupal-Oren-Noam-Nikita.git
cd 26b-10142-final-drupal-Oren-Noam-Nikita/
```

### 2. מתן הרשאות הרצה לסקריפטים
יש לתת לסקריפטים הרשאות מתאימות על מנת שיהיה ניתן להריץ אותם -

```bash
chmod +x scripts/*.sh
```

### 3. הרצת הסביבה
יש להריץ את הסקריפט ליצירת הסביבה (`setup.sh`) -

```bash
./scripts/setup.sh
```
*מומלץ לחכות דקה עד שהאתר יעלה, ולאחר מכן להמשיך לשלב הבא.*

**הערה חשובה -** הסקריפט נכתב בצורה לפיה כאשר יריצו אותו, הוא קודם ינסה לאתר גיבוי ורק אם לא יהיה גיבוי תתבצע התקנה נקייה.
בעקבות הדרישה ליצור משתמשים ולהכניס תוכן, יצרנו מראש גיבוי שיכיל את הסביבה הקיימת.

### 4. כניסה לאתר והגדרת Drupal
* פתחו את הדפדפן והיכנסו לכתובת: `http://localhost:8080`

**במידה והאתר כבר הוגדר -**  
ניתן להיכנס עם פרטי השמתמש בהוראות המטלה והכל מוכן!

**במידה והאתר צריך לעבור הגדרה ראשונית -**  
* עקבו אחר ההוראות של מסך ההתחלה והגדירו את האתר כרצונכם
* במסך חיבור למסד הנתונים (Database Configuration), הזן את הפרטים הבאים  
(**בדיוק** כפי שהוגדרו בקובץ `compose.yaml`):
  * **Database name:** `drupal_db`
  * **Database username:** `drupal_user`
  * **Database password:** `my-secret-pw`
  * **חשוב -** תחת הגדרות מתקדמות (Advanced Options), בחרו את ה-Host בתור: `postgres`
* סיימו את ההתקנה והגדירו את משתמש האדמין של האתר (Admin - username, password, email).

זהו, הכל מוכן!
